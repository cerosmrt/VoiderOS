VOID / PERSONAL WRITING SYSTEM
-------------------------------
- Void scanner: on startup, Voider scans /void recursively, indexes all .txt files
  Index includes: file path, chapter titles, book groupings
  F3 shows chapters from all files across entire void
  Source files never modified

- Book compiler: from F3, select a book and trigger export
  Generates: table of contents, PDF, EPUB (optionally HTML/DOCX/Markdown)
  Triggered via keyboard command inside Voider
  Output saved to configurable output directory
  Source files never modified

- TTS local (two modes):
  Mode 1 — on demand: select file or block, keyboard command reads it aloud
  Mode 2 — I mode: reads ~/void/I.txt from random sentence, loops infinitely
  Engine: piper-tts or espeak-ng (free, offline, lightweight)
  Runs in background while Voider is in use

- Website generator: Python script reads /void, generates static HTML site
  One page per chapter, index per book, global index, quotes page, tags page
  Runs on save or triggered manually from Voider
  Single source of truth: the .txt files. Never modified.

- TTS website (godplaystheartist.com):
  On page load, "I" begins playing from random sentence, loops infinitely
  Feels like the book is always being read — visitor tunes in mid-reading
  Source: same I.txt from /void
